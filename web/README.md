# Timbre 听书 · iPad / 浏览器版

播放 `www.yujizi.org` 上音频的 PWA。不依赖后端，不需要 Xcode，不需要应用商店。

## 运行

```sh
pnpm install
pnpm dev        # 开发，热更新
pnpm test       # 单元测试
pnpm build      # 类型检查 + 构建到 dist/
pnpm preview    # 预览构建产物
```

## 部署

`pnpm build` 产出纯静态文件，整个 `dist/` 上传到站点任意子路径即可，例如 `www.yujizi.org/app/`。
构建时 `base` 设为 `./`，所以子路径无需额外配置。

部署后 **必须用 HTTPS**（或 localhost）打开，否则浏览器不会注册 Service Worker，离线下载不可用。

## 在 iPad 上安装

Safari 打开 → 「分享」→「添加到主屏幕」。之后从桌面图标启动即为全屏。

装到主屏幕还有一个实际作用：**免除 Safari 对 7 天未访问站点清除脚本存储的策略**，
否则下载的音频可能被系统清掉。

## 功能

- 书架列出站点上的全部书目
- 章节列表、播放、倍速（0.75×–2×）、上一章/下一章
- 断点续播：记住每本书听到的位置，恢复时回退 3 秒接上上下文
- 书签：记录当前位置，可跳转、删除
- **离线下载**：按集或整本下载，下载后无网也能听

## 离线下载怎么用

在书本页面：

- 单集右侧点「下载」
- 顶部「下载整本」批量下载剩余章节（已下载的会跳过）
- 已下载的章节会显示 ✓ 和占用体积

在书架右上角「离线」页：

- 查看已下载总量与浏览器存储用量
- 按书清除，或一次性清除全部

### 为什么必须手动下载

浏览器播放音频时只会请求**字节片段**（HTTP 206），不会取回完整文件，
所以「边听边自动缓存」在技术上不成立。下载是显式动作：取回完整文件后存入 Cache Storage，
之后由 Service Worker 用范围请求从缓存供给。

### 存储可能被清掉

浏览器的存储配额按**可用磁盘空间**浮动，磁盘紧张时会按整个站点清除。
所以下载是**缓存**，不是备份：被清掉后重新下载即可，不会丢任何个人数据。
实在担心的话，装到主屏幕可免除 Safari 的 7 天清理策略。

## 已知限制

- **锁屏与后台不能续播**。这是 iOS 对网页应用的一刀切限制，只有原生 App 能绕开。
  合上盖子会停，屏幕亮着时可正常播放。
- **只在屏幕亮着时可靠**。属于上一条的直接后果。
- **依赖站点 HTML 结构**。站点没有 JSON 接口，书目与章节从页面解析。
  站点改版需要同步更新 `src/core/source/yujizi.ts`。
  两个纯文字页面（`玉师聊阴符经`、`玉师聊修行`）本来就没有音频，会友好提示而非报错。
- **必须带 `www.`**。裸域名 `yujizi.org` 无法解析。

## 目录

```
src/
├── core/
│   ├── domain/          数据类型与错误
│   ├── source/          站点抓取与解析（含真实 HTML 测试夹具）
│   ├── storage/         IndexedDB（进度、书签、下载索引）
│   ├── downloads.ts     下载管理器
│   ├── downloads-store.ts  界面层下载状态
│   └── library.ts       书目与章节加载
├── player/              播放器与播放决策
├── views/               书架、播放器、离线、书签
└── service-worker.ts    预缓存外壳 + 缓存音频（范围请求）
```

改动本目录前请先读 [`AGENTS.md`](./AGENTS.md)。
